# IK Instrumentkoder

Installerbar PWA til opslag og træning af instrumentkoder med kundespecifikke kodebiblioteker.

## Åbn og installer

App: https://freddybj95.github.io/aut-software/Instrument-koder/

- iPhone/iPad: Åbn linket i Safari, tryk **Del**, og vælg **Føj til hjemmeskærm**.
- Android: Åbn linket i Chrome, åbn browsermenuen, og vælg **Installer app**.

Efter første indlæsning kan appen bruges offline.

## Filer

Filerne i denne mappe bruges af GitHub Pages. `dist/` indeholder den samme version til alternativ hosting.
