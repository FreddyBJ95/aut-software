# Regulering og kalibrering

Denne mappe samler noter, procedurer, tjeklister og beregningseksempler til regulering og kalibrering af udstyr.

## Foreslået opdeling

- Måleprincipper og signaltyper
- 4–20 mA og 0–10 V
- Tryk, temperatur, niveau og flow
- Nulpunkts- og spanjustering
- PID-regulering
- Kalibreringsrapporter
- Fejlfinding og sikker jobanalyse

## Skabelon til en procedure

1. Formål og udstyrstype
2. Sikkerhed og afspærring
3. Referenceudstyr og sporbarhed
4. Område, enhed og tolerancer
5. Måling før justering
6. Justering og ny måleserie
7. Resultat, afvigelse og godkendelse
8. Dato, instrument-ID og signatur
